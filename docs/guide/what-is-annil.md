# 什么是 Annil

annil 是面向微信小程序原生开发的 TypeScript 框架，基于原生小程序框架能力,提出了一套新的原生开发范式,亦可理解为定制版的原生开发框架,这使得代码逻辑更清晰,AI Agent 维护更容易。

## 解决的问题

annil 解决了包含但不限于以下问题：

- 类型安全: 原生API存在类型不完善/不严格，类型库更新缓慢
- 组件构建: 原生组件构建方式使复杂组件逻辑混乱，阅读/维护困难。
- 能力缺失: 原生组件构建 API 缺少计算属性(computed),全局状态(store)管理等配置方案。
- 组件文件: 组件文件(.wxml/.json/.ts )缺少数据和类型检查。
- AI Agent: annil 让 AI Agent 维护小程序更容易,减少重复知识,降低token成本。

## vscode 插件

Annil 提供了 VSCode 插件，用于增强开发体验，包括代码补全、类型检查、组件模板生成等功能。

## AI Agent适配

annil 为AI Agent 提供了完善的配置文件(instructions等)和工具, 无需额外配置。
